Project Details

Personal Portfolio Website

Project Overview

This project is a responsive multi-page portfolio website built to showcase my academic background, technical interests, and software development work. It was designed with a strong focus on usability and web accessibility standards (WCAG 2.1 Level AA).

Technologies Used

  • Semantic HTML5 for clean document structure
  • CSS3 for responsive layout and high-contrast styling
  • JavaScript for client-side contact form validation
  • Git and GitHub Pages for version control and hosting

Key Outcomes

Through this project, I gained practical experience in structuring accessible web interfaces, evaluating usability using Nielsen's heuristics, and verifying accessibility compliance with the WAVE evaluation tool.
